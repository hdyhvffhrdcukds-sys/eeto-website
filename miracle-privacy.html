레이저링크 · MIRACLE Laser CAD CAM

개인정보처리방침

시행일: 2026년 10월 29일

레이저링크는 MIRACLE의 라이선스 발급, 정품 사용권 확인 및 고객지원을 위해 아래 정보를 처리합니다.

1. 처리하는 정보와 목적

  • 라이선스 관리: 고객 표시명, 라이선스 번호, 사용 가능 기능, 허용 PC 수, 유효기간, 사용 상태, 발급·변경 이력. 사용권 제공과 관리에 이용합니다.
  • 프로그램 활성화·재확인: 라이선스 번호, 장치 식별값, PC 이름, 활성화 토큰, 활성화 및 최근 확인 시각, 실행 세션 식별값과 사용 시작·종료 시각. 사용권과 허용 동시 사용 PC 수 확인에 이용합니다.
  • 고객이 이메일·전화로 문의하는 경우: 고객이 제공한 연락처, 문의 내용 및 자발적으로 제공한 자료. 해당 문의 대응에 이용합니다.

장치 식별값은 PC 이름, 사용자 도메인명, Windows 시스템 디렉터리 정보를 바탕으로 프로그램에서 해시값으로 생성합니다. 이 원래 값들을 각각 전송하지는 않지만 PC 이름은 별도로 전송합니다. 서버는 장치 식별값과 활성화 토큰을 추가 해시하여 저장합니다. 라이선스 번호는 관리 목적으로 서버에 저장합니다.

2. 도면과 작업 파일

도면과 WS 작업 파일은 사용자가 지정한 로컬 경로에 저장합니다. 라이선스 활성화·재확인 요청에는 도면 형상이나 WS 파일이 포함되지 않습니다. 고객지원에 파일이 필요한 경우 사용자가 제공할 자료를 선택합니다. 고객의 도면을 광고나 공개 예제로 사용하지 않습니다.

3. 보유기간과 파기

라이선스·활성화 및 관련 고객지원 정보는 라이선스 제공 기간과 종료 후 1년 동안 보관합니다. 기간이 끝나면 관리자가 확인하여 복구할 수 없는 방법으로 삭제합니다. 자동 삭제 기능으로 처리되는 것은 아닙니다. 법령에 따라 보관해야 하는 정보가 있는 경우에는 해당 정보만 법정 기간 동안 별도로 보관합니다. 영구 사용권은 사용권 종료가 확정된 날을 기준으로 합니다.

4. 서비스 제공 업체와 국외 처리

라이선스 서버 운영에는 Cloudflare, Inc.의 Workers 및 D1 서비스를 사용합니다. 처리 목적은 라이선스 요청 처리와 데이터 보관이며, 처리 항목은 위 라이선스·활성화 정보입니다. 활성화와 프로그램 시작·NC 내보내기 시 확인하고, 정상 종료 시 사용 종료 정보를 HTTPS 통신으로 전송합니다. 실행 중 정기적으로 확인하는 방식은 아닙니다.

2026년 10월 28일 확인한 D1 데이터베이스의 운영 지역은 아시아·태평양(APAC)이며, 국가를 고정하는 설정은 없습니다. Cloudflare는 미국에 본사를 둔 글로벌 서비스로, 요청 처리와 보관이 국내에만 한정된다고 보장하지 않습니다. Cloudflare가 제공하는 관리 정보에는 실제 보관 국가가 개별적으로 표시되지 않습니다. 보유기간은 위 3항에 따릅니다.

Cloudflare 개인정보 안내 · Cloudflare 데이터 위치 안내

라이선스 확인에 필요한 정보 처리를 원하지 않는 경우 아래 연락처로 문의하거나 이용 종료를 요청할 수 있습니다. 온라인 활성화·재확인이 필요한 프로그램 사용은 제한될 수 있습니다. 별도 동의 또는 법률상 근거가 필요한 경우 그 절차를 거칩니다.

5. 이용자의 요청

정보 열람·정정·삭제·처리정지 요청은 아래 연락처로 접수할 수 있습니다. 본인 확인 후 처리하며, 법령이나 사용권 확인을 위해 제한되는 경우에는 사유를 안내합니다. 이메일에 관리자 비밀번호나 전체 라이선스 번호를 보내지 마세요.

6. 보호 조치

라이선스 서버는 HTTPS를 사용하고 관리 기능은 관리자 인증으로 제한합니다. 활성화 토큰과 장치 식별값은 서버에서 해시하여 관리합니다. PC에는 활성화 상태가 사용자별 앱 데이터 폴더에 저장됩니다.
